# 數位性暴力／性剝削防治工具（入口）

這是 stop-dsv-tw 的一頁式入口，把目前公開的宣導與實務輔助工具集中在同一頁，方便機關、學校與民間單位一次查看並轉介。各工具均為張博鈞個人製作，免費提供，不代表任何機關立場。

## 🔗 網址

https://stop-dsv-tw.github.io/

頁面上附有同一網址的 QR code，可印在簡報或公文附件。

## 適用對象

供社福、學校、警政、民間團體等專業單位查看、使用與轉介。各工具另有自己的適用對象：

- 《看穿這一局》：國小高年級、國中
- 《說不，也可以》：國中、高中／高職
- 《別衝動》：國中小、高中／高職男生
- 《先接住，再處理》：未滿 18 歲兒少的家長或主要照顧者
- 《性剝削 24 小時引導評估》：第一線社工

## 使用方式

直接開啟網址即可，無需安裝，亦支援手機瀏覽器。可用頁面上的分類查看「學生教材」「家長」「實務工作者」。點「開啟」會進入該工具（網址帶 `?src=portal`，僅供匿名統計來源，不影響工具運作）。

《先接住，再處理》卡片提供「給家長掃 QR」，可顯示並下載給家長掃碼的直式圖片；頁尾亦可下載入口頁的手機版 QR 圖。

用於《看穿這一局》《說不，也可以》《別衝動》的個案工作時，請由受過訓練的專業人員全程陪同；《看穿這一局》用於國小學童時，同樣請專業人員全程陪同，不要讓孩子單獨使用。

本網站使用 GoatCounter 進行匿名流量統計，不使用 cookie、不蒐集可識別個人的資料。
